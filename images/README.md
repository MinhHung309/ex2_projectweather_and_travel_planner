# Thư mục hình ảnh dự án (Images)

Thư mục này dùng để lưu trữ các tài nguyên ảnh cục bộ phục vụ ứng dụng nếu cần (ví dụ: ảnh nền chất lượng cao, icon tùy chỉnh, ảnh minh họa điểm đến).

Ứng dụng hiện tại đã tích hợp sẵn hiệu ứng gradient Glassmorphism phản chiếu ánh sáng (Ambient Glow) và mã màu dự phòng đảm bảo hoạt động độc lập không phụ thuộc mạng.
